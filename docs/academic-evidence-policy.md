# Academic evidence and citation policy — UPC dossier

## Mandatory claim classification
Every consequential claim must be marked in working drafts as one of: **PEER_REVIEWED**, **OFFICIAL_SOURCE**, **REPOSITORY_OBSERVED**, **REPOSITORY_REPORTED_RESULT**, **AUTHOR_STATEMENT**, **PROPOSED_HYPOTHESIS**, or **INDEPENDENTLY_REPRODUCED** (only after actual replication).

## Required evidence metadata
Record claim ID, exact wording, source title, author/institution, year, DOI or persistent URL, retrieval date, exact page/section/file path and commit SHA, method of verification, geographic and temporal scope, limitations and whether public disclosure is permitted.

## Scientific writing rules
1. Use IEEE numbered references provisionally, consistently across sections.
2. Prefer peer-reviewed hydrology/AI work for scientific framing, and SGB/ANA/Cemaden/Defesa Civil primary records for event chronology and data definitions.
3. Never use a reference about the Taquari flood as proof of GeoAlerta model performance.
4. Separate code existence, tests, retrospective evaluation, independently replicated results and live deployment.
5. Do not claim that heterogeneous information had never been integrated before; define measurable fragmentation (latency, schemas, coverage, datum, source authority, missingness).
6. State portability as a configurable architecture and testable hypothesis, not established city-independent accuracy.
7. Keep private source code and personal academic documents out of this public documentation repository unless specifically approved.
8. Before sending to Prof. Cano, verify full citation metadata, license conditions, numerical claims and applicant's individual authorship.

## Suggested chapter structure
Background and motivation; 2023–2024 Vale do Taquari case; state of the art; data fragmentation and provenance; GeoAlerta Sul system architecture and endpoint traceability; forecasting models and experimental design; uncertainty, explainability and governance; cross-city transfer protocol; applicant contribution; limitations; reproducibility; references.
