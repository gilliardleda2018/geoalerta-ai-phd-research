# Preliminary GeoAlerta AI code audit — 2026-10-26

**Scope:** read-only inspection of selected files in private GitHub repositories. No code execution, independent metric replication, or comprehensive security/data audit has been performed. Do not copy private source or operational data into this public dossier.

## Observed repositories
- gilliardleda2018/geoalerta-ai (private): Tuntum flood-risk pipeline, GeoJSON, terrain raster, rainfall and scenario outputs; `pipeline/atualizar_modelo_com_chuva_dinamica.py` uses RandomForestClassifier.
- gilliardleda2018/geoalerta-sp (private): São Paulo geospatial risk scripts, `scripts/treinar_modelo_risco_sp.py` uses RandomForestClassifier and topographic/hydrological features; GOES-19 Band 13 ConvLSTM model metadata present.

## Key scientific cautions
1. In SP random-forest training, target labels are generated by deterministic thresholds on predictor variables. Random train/test accuracy on these synthetic labels tests replication of the rule, **not independent real-world flood prediction skill**. Spatial holdouts and observed flood labels are needed.
2. In Tuntum dynamic rainfall script, class labels are derived from the input risk score, the model is fitted and predicted on the same rows, and rainfall is a constant for all rows in that run. Do **not** report its outputs as validated forecasting accuracy.
3. SP ConvLSTM historical metadata file reports 998 samples, 798 training and 200 validation, GOES-19 Band 13, validation MAE 0.2230324745 and best validation loss 0.1086454168. These are **repository-reported metrics**, not independently reproduced or necessarily physical-unit performance. Split design, normalization, leakage, baselines and external validation remain unverified.

## Research opportunity
Build evaluation on observed event labels, temporal and spatial holdouts, well-defined baselines, calibration, uncertainty quantification, explainability and deployment-relevant decision metrics.
